This is an android app to convert markdown text to a PDF document.

It should have a view with a text view that shows the markdown, and a button "Paste" which when pushed will paste the text contents to the text view.

There should be a button that when pushed converts the text (assume markdown) in the text view to a PDF document.
There should be a zoom functionality, which will set the relative size of the text e.g. relative between headings and text. There is no need to accomadate markdown such as diagrams or images or formulas or tables. This will be used purely for text such as headings (h1-h4), bullet points, numbered lists and plain text.
The paper size should be A4. The margins should default to 2 centimeters.

There should be a preview of what the PDF looks like, and a way to save this to a PDF file on the device, e.g. to the Downloads folder (which is a nice dumping ground of files).
