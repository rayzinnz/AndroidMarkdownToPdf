**Host a Minimal Privacy Policy**

Create a new github repository called "privacy-policy"
Set the visibility to Public
Add a README file

Add an index.html
```html
<h1>Privacy Policy</h1>
Effective Date: 22 August 2026</br>
I have developed this app as a free/commercial app.</br>

<h2>Information Collection and Use</h2>
This application does not collect, store, transmit, or share any personal information or sensitive user data. We do not use third-party tracking, analytics SDKs, or advertisements.</br>

<h2>Contact Us</h2>
If you have any questions or suggestions regarding this Privacy Policy, do not hesitate to contact us at raymond.gabriel@gmail.com.</br>
```

Settings\Pages\Build and Deployment
Set branch to main
Save

Refresh Settings\Pages
